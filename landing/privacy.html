1. 取得・処理する情報

Taskmetry は、CPU と物理メモリの使用状況を実行 PC 内で計測します。Codex の使用率表示ではOpenAI公式のCodex App Server APIから、Claudeの使用率表示では claude.ai の組織・使用率Web応答から、利用枠やリセット時刻などを取得します。ローカルの会話、セッション記録、CLI出力は読み取りません。

2. Web認証と外部通信

ユーザーがCodexの「Webで接続」を選ぶと、Taskmetryは既定のブラウザーでOpenAI公式認証画面を開きます。認証処理、トークンの保存、更新はCodex App Serverが担い、Taskmetryはパスワードや認証トークンを受け取ったり保存したりしません。接続後は公式使用率APIへ定期的に通信します。

Claude接続では、ユーザーがブラウザーから手動取得した sessionKey を入力します。Taskmetryは接続確認時と定期取得時に、この値をCookieとして https://claude.ai だけへ送信します。Claudeの使用率エンドポイントは公開APIではないため、Claude側の仕様変更によって取得できなくなる場合があります。

CPU・メモリの計測値、会話本文、ローカルログは外部へ送信しません。広告、解析、利用状況テレメトリも組み込んでいません。

3. 更新確認の通信

Velopack でインストールされた Taskmetry は、起動時およびユーザーが「更新を確認」を選んだとき、taskmetry.kagayoi.com へ HTTPS で更新 manifest を問い合わせます。更新を選択した場合は、同じ配信元から署名済み更新ファイルを取得します。通常の Web 配信と同様、配信基盤側で IP アドレスや User-Agent などのアクセス情報が一時的に処理される場合があります。

4. ローカル保存

表示項目、幅、更新間隔、レイアウト編集モードなどの設定は実行 PC 内へ保存されます。Claudeの sessionKey は設定JSONやログへ記録せず、接続確認に成功した後だけWindows資格情報マネージャーへ保存します。設定画面でClaudeの接続を解除すると、この資格情報も削除します。

5. お問い合わせ

不具合やプライバシーに関する連絡は、GitHub Issues へお願いします。
